# Web feature components

Internal-domain components are grouped by product area: `identity`,
`workspace`, `finance`, `growth`, `telegram`, and `operations`. Independent
product UI lives with its product: Finance Pro in `products/finance-pro/web`
and Greeter in `products/greeter/web`.

Reusable controls and page-independent components stay in `components/ui`, `components/icons`, and `components/layout`.
